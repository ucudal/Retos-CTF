# UCU's CTF Knowledge Base

Este repositorio está orientado a **documentar**, **organizar** y **compartir los conocimientos adquiridos** durante la resolución de desafíos de CTF.

## Sobre el proyecto
Este repositorio fue creado por un grupo de estudiantes de Informática de la UCU en el marco del Reto 3 Diciembre 2024, un desafío que busca fomentar el aprendizaje y la práctica de ciberseguridad a través de la resolución de problemas concretos.

Como parte de nuestra preparación, realizamos el SANS Holiday Hack Challenge, una competencia anual organizada por SANS. Este evento incluye una serie de desafíos de ciberseguridad en áreas como análisis forense, redes, explotación web, ingeniería inversa y más, con el objetivo de desarrollar habilidades técnicas avanzadas en un entorno práctico y lúdico.

# Propósito del repositorio
El objetivo principal de esta base de conocimientos es:

- Documentar las soluciones a desafíos de CTF y los aprendizajes asociados.
- Facilitar la organización y el acceso a recursos útiles para estudiantes interesados en ciberseguridad.
- Servir como guía de referencia para futuros desafíos y competiciones.
- Promover el aprendizaje colaborativo dentro de la comunidad académica.
